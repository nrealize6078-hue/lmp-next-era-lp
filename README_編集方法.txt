LIFE MAKE PARTNERS｜新時代の集客 LP 編集用データ

【表示する】
ZIPをすべて展開し、index.htmlをChromeやEdgeで開いてください。
インストール不要。2つの集客モデルの切り替えも動きます。

【ファイルの役割】
index.html：見出し・文章・リンク・ページ構成
style.css：色・文字サイズ・余白・スマホ対応
script.js：2つの集客モデルを切り替える動作
hero.png：夕暮れの街のメイン画像（AI生成）
LP_原稿.txt：文章だけの修正相談用原稿

【編集する】
1. 元のフォルダーをコピーしてバックアップします。
2. index.htmlをコードエディターで開き、文章を検索して変更します。
   <h1>や<p>等のHTMLタグを残し、その中の文章を編集してください。
3. UTF-8で保存し、ブラウザーを再読み込みして確認します。
4. スマホ幅での改行やボタンも確認してください。

【デザインを変える】
style.css冒頭の --navy（濃紺）、--gold（ゴールド）などを変更できます。
画像を差し替える場合はhero.pngを同名画像に置き換えるか、
index.html内の画像ファイル名を変更してください。

【文章だけを修正したい方へ】
LP_原稿.txtを編集してWeb担当者へ渡せます。
この原稿の編集はLPへ自動反映されません。
ChatGPT等で編集する場合は、このZIPを添付して変更箇所を伝えてください。

【問い合わせ先（LINE）】
問い合わせ導線はLINE公式アカウントに一本化しています。設置箇所は2つです。
1. 最終CTA（ページ下部の白いカード）
2. 固定ボトムバー（ヒーローを過ぎてから画面下に出ます）
リンク先は現在 https://lin.ee/vV1leDB です。変更するときは
index.html内のこの文字列をすべて置換してください（4か所あります）。
ボタン画像はLINE公式の配布画像を読み込んでいます。
画像が表示できない環境では、同じリンクの緑色ボタンへ自動で切り替わります。

【固定ボトムバーを消したいとき】
index.html末尾の <div class="cta-bar" ...> ～ </div> を削除してください。
削除してもほかの表示は崩れません。

【公開について】
静的HTML/CSS/JavaScriptのため、通常のWebサーバーで公開できます。
LINE以外のボタンはページ内移動用で、フォーム送信機能はありません。
「地域独占」の表現や募集枠・加盟条件は確定条件に合わせてください。

元の確認用サイトは所有者限定です。このZIPを渡しても、そのサイトの編集権限は付きません。
ローカルで編集しても元サイトは変わりません。更新データを所有者へ返して再公開するか、
社員さんが管理するWebサーバーで公開してください。
